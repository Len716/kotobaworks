# Google Form テンプレート

明日以降、Google Form で2つのフォームを作成する際のテンプレートです。

## フォーム1: Talent Session（個人向け）申し込み

| 質問 | 形式 | 必須 |
|---|---|---|
| お名前 | 記述式（短文） | ○ |
| メールアドレス | 記述式（短文） | ○ |
| 希望プラン | プルダウン：Single / Complete / Partner / まだ決めていない | ○ |
| 希望方式 | プルダウン：AI Session（無料）/ Human Session（¥5,000） | ○ |
| 希望日時 | 記述式（長文） | ○ |
| ひとこと（任意） | 記述式（長文） | × |

**フォーム設定:**
- 回答のコピーを回答者に送信: ON
- 回答の編集を許可: OFF

---

## フォーム2: Sales Partner（法人向け）お問い合わせ

| 質問 | 形式 | 必須 |
|---|---|---|
| 会社名 | 記述式（短文） | ○ |
| お名前 | 記述式（短文） | ○ |
| 役職 | 記述式（短文） | ○ |
| メールアドレス | 記述式（短文） | ○ |
| 電話番号 | 記述式（短文） | × |
| 関心のあるパッケージ | プルダウン：Starter / Standard / Premium / まだわからない | ○ |
| 現在の課題（任意） | 記述式（長文） | × |

**フォーム設定:**
- 回答のコピーを回答者に送信: ON
- 回答の編集を許可: OFF

---

## 作成後の手順

1. Google Form を2つ作成
2. 各フォームの共有URL（短縮版）をコピー
3. Claude Code に「フォームURL: [個人用] xxx / [法人用] xxx」と伝える
4. 全ページの mailto リンクをフォームURLに一括差し替え
